The name is familiar, but the letters are scrambled. In CrossOver’s Çöz Kazan mode, both players see the same puzzle and the first correct full name wins the round.

How the anagram match works

  1. A match has seven regular rounds, each with a different scrambled footballer name.
  2. Both players race at the same time. Each round lasts 20 seconds; the first correct answer earns the point.
  3. A wrong answer locks your input for five seconds. You can try again if the round is still running when the lock ends.
  4. Each word is shuffled separately. Enter the displayed full name; players recorded under one name have one word.
  5. A tied score after seven rounds leads to extra sudden-death rounds. If those remain unresolved, the match can end in a draw.

A practical way to solve names faster

Start with word lengths. Two short words and one long surname suggest different names. Then look for repeated or unusual letters: a doubled letter can quickly rule out an otherwise tempting guess.

Before submitting, account for every letter. This mode checks the complete name, so relying on approximate spelling can cost five seconds. Capitalisation, spaces and punctuation do not change the match; plain equivalents of Turkish letters are accepted.

Frequently asked questions

Is a surname enough in the football anagram game?
No. For a multi-word name you need the complete displayed name. A footballer recorded under a single name needs that one word.
Are letters shuffled across the entire name?
No. Each word is shuffled separately, preserving the word lengths as separate groups.
Does a wrong answer end the round?
No. Your input is locked for five seconds. You may try again if time remains and the opponent has not already solved it.
Is this the same as Letter–Club?
No. Anagrams give you the letters of one specific name. Letter–Club asks you to name any eligible footballer matching a letter and a club.
