# Crossover Webapp

Bu klasor, mobil uygulamanin ayni arayuz ve akisini ayri bir web sitesi olarak calistirmak icin ince bir Expo wrapper projesidir.

## Calistirma

```bash
cd webapp
npm run web
```

Varsayilan adres: `http://localhost:8091`

Bu wrapper, gorunur arayuzu `../app/App.tsx` uzerinden dogrudan mobil uygulamadan alir.
